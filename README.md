# Лабораторная работа №1
## Обработка строки символов различными способами хранения

### Задание №21
**Переставить все слова в строке в обратном порядке, если длина строки больше 10 символов и содержит хотя бы одно заглавное слово. Иначе — поменять местами первое и последнее слова.**


### Алгоритм обработки
1. **Анализ условий** - Проверяется наличие хотя бы одного «заглавного» слова (все буквы которого — прописные)
2. **(Условие 1): Если длина > 10 И есть заглавное слово** - реверс списка слов
3. **(Условие 2): В противном случае (если хотя бы одно условие не выполнено)** Находятся первое и последнее слова в строке.Эти два слова меняются местами, остальные части строки остаются без изменений.

### Пример работы
**Входная строка:** `Мама мыла КРАСИВУЮ раму`

**Обработка:**
- Длина 24 > 10, есть слово «КРАСИВУЮ»
- Определяем слова: Мама, мыла, КРАСИВУЮ, раму
- Переставляем в обратном порядке

**Выходная строка:** `раму КРАСИВУЮ мыла Мама`

# Семинар 1: Алгоритмы сортировки

Реализация различных алгоритмов сортировки на C++ с тестами.

## Алгоритмы
- Сортировка вставками (Insertion Sort)
- Сортировка выбором (Selection Sort) 
- Сортировка обменом (Exchange Sort)
- Сортировка пузырьком (Bubble Sort)
- Сортировка пузырьком с улучшениями (Optimized Bubble Sort)


## Использование
Все алгоритмы реализованы как шаблонные функции, поддерживающие различные типы данных.
